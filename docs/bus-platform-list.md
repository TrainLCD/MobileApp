# 周辺のバス路線一覧

Figma A案に沿って、同じ事業者・路線名の系統をまとめます。
複数系統は初期状態で折りたたみ、見出しを押すと一覧を開閉します。
単独系統は路線カラーのカードを表示し、見出しから直接選択します。
停車駅一覧と同じ `CommonCard` のアコーディオンを使用します。

- 「47A 新前橋駅西口線」のような系統番号と路線名の併記を分離します。
- 数字を含む英数字の系統番号と空白がある場合だけ分離します。「名駅２４」などはそのまま表示します。
- 事業者IDまたは路線名がない場合は、路線IDごとに分けます。
- のりば情報の有無は集約条件に使いません。補足ののりば表示には数字だけの値を使います。
- 複数系統を展開できるグループを先に、単独系統を後に表示します。各区分内のグループ順と、グループ内の系統順はAPIの掲載順を維持します。
- 同じ系統番号が複数ある場合は、取得済みの `nameRoman` に詳細名があれば各行に補足します。GTFS取込では路線長名の英訳、なければ路線長名をこのフィールドに格納します。空欄や既存の路線名と同じ値の場合は補足しません。
- 展開行には系統番号と路線名を常に表示します。のりば・詳細情報がある場合だけ、路線名の下に補足行を表示します。
- 現在駅が変わると開閉状態をリセットします。
- ロード中は系統を選択できません。複数系統の開閉はできます。

PR #7421で採用したのりば別集約と、情報欠落時の従来一覧への切り替えを置き換えます。
鉄道とバスを別セクションにする構成、既存の路線選択処理は維持します。
