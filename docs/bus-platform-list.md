# 周辺のバス路線一覧

周辺のバス路線にのりば情報がある場合、のりばごとに系統をまとめます。
初期状態は折りたたみです。見出しを押すと系統一覧を開閉できます。
系統を押すと従来の路線選択処理へ進みます。
停車駅一覧と同じ `CommonCard` のアコーディオンを使用します。

- 全系統で `line.station.platformCode` が空の場合は、従来のカード一覧を表示します。タブレットの列数も維持します。
- 一部の系統でのりば情報がない場合は、一覧の末尾の「その他」にまとめます。
- 別の停留所の同じのりば番号は、別のグループとして表示します。
- のりばと系統の並び順は、APIの掲載順を維持します。
- 現在駅が変わると開閉状態をリセットします。

鉄道とバスを別セクションにする既存の構成（PR #4902）は維持します。
バス側の系統カードを常時表示する部分だけを、のりば情報があるときに集約します。
