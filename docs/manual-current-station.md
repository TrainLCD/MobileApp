# 走行中の現在駅の補正

走行中の設定で、列車種別の下にある「駅を指定する」を押します。
駅を選ぶと、現在駅を更新して設定を閉じます。
列車種別がない路線でも利用できます。
駅一覧はCommonCardで表示し、駅名と路線名を確認できます。

- 一覧には、確定済みの運行経路（`stations`）に含まれる駅をそのまま表示します。直通先の駅と区間内の通過駅も含めます。
- 起点より前や行き先より先の駅、別の系統だけにある駅は追加しません。例えば福生～布佐の経路では、その区間内の駅だけを候補にします。
- 候補取得のためのAPIアクセスは行いません。駅の順序と種別・通過情報を維持します。
- 列車種別、進行方向、行き先、到着・走行の状態は維持します。接近表示は解除します。
- 補正前と同じ測位結果では現在駅を上書きしません。新しい測位を受理すると自動更新を再開します。
- 「閉じる」や背景のタップでは現在駅を変更しません。
- オートモードでは走行区間と区間内の進行位置も補正し、選んだ駅から進行方向に沿って再開します。通過駅を選んだ場合は、その駅を含む停車駅間の途中から再開します。

`useManualCurrentStation` は運行経路の駅オブジェクトをそのまま使います。経路外の駅は選択できません。
`useRefreshStation` の通過駅の自動補正（#7167）は維持し、手動補正直前の測位を再適用する場合だけ更新を抑えます。
