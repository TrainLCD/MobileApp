# 走行中の現在駅の補正

走行中の設定で、列車種別の下にある「駅を指定する」を押します。
駅を選ぶと、現在駅を更新して設定を閉じます。
列車種別がない路線でも利用できます。
駅一覧はCommonCardで表示し、駅名と路線名を確認できます。

- 一覧には、選択中の運行経路の各路線と、現在駅を通る各列車種別の直通先路線の全駅を表示します。選択中の種別にない分岐先も含めます。
- 駅の取得には、種別で絞らない `lineListStations` を使います。`lineStations` は代表系統を選ぶため、全駅の取得には使いません。
- 全駅の取得中や取得失敗時は、取得済みの運行経路の駅を表示します。直通先の種別情報を取得できない場合は、運行経路と現在路線の全駅を候補にします。
- 同じ駅でも路線ごとに表示します。現在路線だけに候補を絞りません。
- 経路外の駅を手動指定した場合は、同じ駅グループの経路上の駅に置き換えず、指定した駅と路線を表示します。新しい測位・経路・現在駅への更新後は通常の判定に戻ります。
- 列車種別、進行方向、行き先、到着・走行の状態は維持します。接近表示は解除します。
- 補正前と同じ測位結果では現在駅を上書きしません。新しい測位を受理すると自動更新を再開します。
- 「閉じる」や背景のタップでは現在駅を変更しません。
- オートモードで運行経路に含まれる駅を選んだ場合は、走行区間と区間内の進行位置も補正し、選んだ駅から進行方向に沿って再開します。通過駅を選んだ場合は、その駅を含む停車駅間の途中から再開します。

`useManualCurrentStation` は現在駅の全種別から直通先の路線IDを集め、路線の全駅を取得します。運行経路にも存在する駅には、元の駅オブジェクトを使って種別・通過情報を維持します。経路にない駅を選んでも運行経路は変更しません。
`useRefreshStation` の通過駅の自動補正（#7167）は維持し、手動補正直前の測位を再適用する場合だけ更新を抑えます。
