# 駅オブジェクト仕様

## フィールド

- 路線含めた駅そのものを定義する際は testID に `.id` を使う
- 路線を含めない駅グループを定義する際は `.groupId` を使う

## 走行中の種別違いの検知

カナリア版の「設定」→「試験的機能」で「列車種別・バス系統の違いを検知」を
オンにすると、走行画面で停車・通過の食い違いをお知らせします。初期設定はオフです。
オートモード中は、実際の測位による走行を判定しません。

- 鉄道では、停車予定の駅を一定以上の速度で通過した場合に警告します。
- 通過予定の駅に停車した場合は、信号待ちなどを考慮して別々の2駅で確認します。
- バスでは、同じ路線のうち選択した運行パターンに含まれない2箇所の停留所で
  停車した場合に警告します。乗降のない停留所での通過は判定に使いません。
- 測位の精度や更新間隔が判定に必要な条件を満たすときだけ検知します。
  警告は選択ごとに一度表示し、利用者は走行画面から種別を選び直せます。
