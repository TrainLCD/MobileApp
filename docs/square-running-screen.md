# 正方形の走行画面

画面の長辺が短辺の1.2倍以下の場合は、正方形用の走行画面を表示します。
縦画面設定の有無にかかわらず適用します。PiP表示を優先します。
それ以外の画面では、従来の縦画面設定と横画面表示を使います。

初期表示はC案の乗換案内です。ヘッダーや駅名をタップすると、B案の駅一覧に切り替わります。
B案の駅一覧や下段をタップするとC案に戻ります。
スクロール中は表示を切り替えません。駅一覧の先頭駅が変わるとスクロール位置を戻します。
設定ボタンは既存の設定メニューを開きます。C案の乗換路線は既存の路線選択処理を使います。
タッチロック中はこれらの操作を無効にします。

B案では駅名の右にAPI表記の駅番号、その右にポートレートと同じ残り分のETAを表示します。
ETAは現在駅より先の停車駅に表示し、丸めて0分なら「まもなく」、一部未取得なら「--」と表示します。現在駅より先にある表示対象の停車駅にETAが一つもない場合は、列を表示しません。通過駅や表示対象外の駅の推定値はこの判定に含めません。現在駅が前方補正された場合は、補正後の現在駅より先の停車駅だけを表示対象と列の有無の判定に使います。補正後の現在駅が表示順に見つからない場合は、記録上の現在駅を基準にします。
B案では通過済みの駅にラベルを付けず、文字と記号の濃淡で区別します。
B案の下段には「のりかえ」と乗換路線の記号を表示します。
ラベルはアプリが日本語環境なら「のりかえ」、それ以外なら「Transfers」に固定します。路線数と路線名は表示しません。
路線の記号と駅番号は既存のAPIデータと描画コンポーネントを使います。
乗換がない場合は、その旨を表示します。

駅名と状態の文言は既存のヘッダー状態に従います。
C案は日本語と英語を同時には表示せず、中国語・韓国語を含む既存の言語切替に従います。
言語が切り替わっても、C案とB案の選択を維持します。
背景はライト・ダーク設定に従い、路線色と種別色はデータを使います。

## Galaxy Z Flipのカバー画面

SamsungのFlex Window向けに「TrainLCD カバー画面」ウィジェットを追加しています。
カバー画面のウィジェット一覧で有効にし、タップするとカバー画面を指定してアプリを開きます。
既存のホーム画面ウィジェットの登録と起動先は変更しません。
起動後は既存のナビゲーションを使います。乗車中であれば走行画面を表示します。

ウィジェットにはSamsung指定の`sub_screen`メタデータと`keyguard`カテゴリを設定しています。
起動には`ActivityOptions.launchDisplayId = 1`を使います。
端末のロックとOSの起動制限には従います。
Good LockのMultiStarからアプリを起動する方法もSamsungが案内しています。

Androidでは画面サイズの変更イベントを購読し、ウィンドウの寸法が変わらない場合も表示を再判定します。
Androidではウィンドウだけでなく、装飾領域を含む画面の縦横比も正方形判定に使います。
画面全体による補正は、ウィンドウの各辺が画面全体の70%以上100%以下の場合に限定します。
これは表示領域を確保するためのアプリ側の基準で、OSの分割画面状態を判別するものではありません。
360×374の画面で360×280のウィンドウは補正し、360×180の半画面ではウィンドウ自体の縦横比で判定します。
描画領域では既存のSafe Areaを使い、画面の上下左右のインセットを確保します。
MainActivityには既にリサイズ許可と画面サイズ変更への追従設定があります。

仕様の出典:

- [Samsung Flex Window: ウィジェット登録と起動先の指定](https://developer.samsung.com/galaxy-z/flex_window.html)
- [Samsung: Good Lockからの起動と画面サイズへの対応](https://developer.samsung.com/sdp/blog/en/2024/01/09/best-practices-of-app-development-for-various-screen-sizespowered-by-good-lock)

実機確認の項目:

- カバー画面の一覧にウィジェットが現れ、タップでカバー画面にアプリが開くこと。
- 本体画面で乗車を開始してから、カバー画面でも同じ乗車状態を表示すること。
- C案とB案の切替、日英切替、設定画面が使えること。
- カメラ部分とシステムバーに文字や操作部分が隠れないこと。
- 開閉後に画面サイズと操作領域が更新されること。

B案はポートレートと同じアプリの言語判定を使い、日本語環境では漢字、それ以外では英語に固定します。駅名・路線名・種別・方面・乗換ラベル・ETAの文言を同じ言語に揃えます。C案の駅名と状態表示は既存の全言語の切り替えに従います。C案の乗換案内は、見出し・路線名・乗換駅名・乗換なしの文言を日本語環境では日本語、それ以外では英語に固定します。

B案・C案とも、上部ヘッダーの路線名・種別・方面は環境の言語に固定します。C案の駅名・状態表示の言語切り替えは維持します。

C案の停車中表示はポートレートと同じ補完処理を使います。共有ヘッダーの状態文言が空になる英語・中国語・韓国語でも、各言語の「ただいま停車中」を表示します。
