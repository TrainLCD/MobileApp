# 振り返り機能の乗車ログ

振り返り機能 ([#5751](https://github.com/TrainLCD/MobileApp/issues/5751)) が集計に使う乗車ログの記録方法をまとめます。

## 記録するユーザー

記録はオプトインです。
`rideLogEnabledAtom`（MMKV キー `@TrainLCD:rideLogEnabled`）が `true` のときだけ、
Main 画面に記録用の `FxRideRecorder` をマウントします。既定は `false` です。

設定は「設定 > 振り返り」（`src/screens/RideLogSettings.tsx`）で切り替えます。
オフにしても保存済みの記録は消しません。
記録を消すのは、同じ画面の「記録をすべて削除」だけです。
削除は記録の書き込みと同じ列（`enqueueRideLogMutation`）に並べて実行します。
Main 画面を抜けたときの最後の書き込みが終わってから消すので、削除した乗車が作り直されることはありません。

## 保存先

端末内の SQLite (`rides.db`) にだけ保存します。サーバには送りません。
利用者の位置の座標は保存せず、検出した駅と時刻、その駅の座標と都道府県だけを持ちます。
駅の座標と都道府県は StationAPI が返す駅のデータで、移動経路の地図と都道府県ごとの集計に使います。

| テーブル | 1行の意味 |
| --- | --- |
| `ride_sessions` | 1回の乗車。開始・終了時刻、路線、種別、方面 |
| `ride_stops` | 乗車中に検出した駅。`kind` は `arrived`（到着）か `passed`（通過） |

時刻はエポックミリ秒で持ちます。週・月・年への振り分けは、集計する側が端末のタイムゾーンで行います。路線名・路線色・駅名は記録した時点の値を残します。駅データが後から変わっても、過去の記録を表示できるようにするためです。

## 1回の乗車

- Main 画面を開いてから抜けるまでを1回の乗車として扱います。
- 画面を開いた時点の駅を出発駅とします。
- 出発駅の次の駅への到着を1回検出するまでは、DB に書かずメモリに溜めます。画面を開いただけのセッションや、ホームで待っているだけのセッションを数えないためです。通過駅を検出しただけでは確定しません。
- 確定したら、それまでに検出した駅をまとめて1トランザクションで書きます。書き込みに失敗したら、次に駅を検出したとき・発車したとき・Main 画面を抜けるときに、それまでの駅ごと書き直します。書く内容は書き込みを実行する時点のメモリから決めるので、書き込み待ちのあいだに検出した駅も取りこぼしません。以降は駅を検出するたびに追記するので、アプリが終了されても最後の到着までは残ります。
- オートモードを一度でも有効にしたら、Main 画面を抜けるまで記録しません。オートモードの駅移動は実際の乗車ではないためです。
- 直通運転の接続駅は、駅リストに前の路線の駅と次の路線の駅として2回並びます（`src/utils/dropJunctionStation.ts`）。
  到着判定がこの2つを行き来しても、同じ駅なので2度目は書きません。
  次の駅までの距離は、後から検出した方の駅から測ります。
  通過として書いた駅に停車したと分かったときだけ、到着を残すために書きます。

## 時刻

- `ride_sessions.startedAt` は、出発駅を発車した時刻です。発車を検出できなかった場合は、Main 画面を開いた時刻にします。
- `ride_sessions.endedAt` は、最後に到着を検出した時刻です。通過では更新しません。
- `ride_stops.departedAt` は、駅の到着圏を出た時刻です。出入りを繰り返した場合は、最後に出た時刻で上書きします。
- `ride_stops.etaMinutesFromPrevious` は、ETA 上の所要時間（分）です。
  StationAPI の `estimateArrivalTimes` が駅間距離と車両性能から求めた時刻を、`useEstimateArrivalTimesRoute` で取得して使います（`src/utils/rideEta.ts`）。
  この乗車で前に ETA を引けた駅から、その駅までを数えます。
  前の駅が出発駅なら発車の時刻から、それ以外なら到着（通過）の時刻から数えるので、途中の駅の停車時間も入ります。
  乗車の中で足すと、出発駅の発車から最後の駅までの所要時間になります。
  ETA を引けなかった駅と、この列を足す前に記録した行は `null` です。

到着圏を出入りした時刻だけでは、発車直後と停車直前の時間が抜けます。
到着圏の半径は駅間距離の 1/4 で、75〜200 m に収めています（`src/hooks/useThreshold.ts`）。
駅間が 1 km ほどの区間では、測れるのは真ん中の 600 m ほどだけです。
ETA の所要時間は、この抜けを補うために記録します。

## 距離

`ride_stops.distanceFromPrevious` は、直前に記録した駅からの距離（メートル）です。出発駅は 0 です。

乗車中の駅リスト上で2駅のあいだにある駅をたどり、隣り合う駅どうしの距離を合計します（`src/utils/rideDistance.ts`）。
GPS が途切れて途中の駅を検出できなかった区間も、この方法で埋めます。環状線は、短い方の回り方をとります。

隣り合う駅どうしの距離には、StationAPI が `lineStations` / `lineGroupStations` / `stations(ids)` で返す線路の長さ（`trackDistanceFromPrevious`）を使います。
StationAPI はこの値を「返す並びで直前にある駅からの長さ」として返します。
`stations(ids)` は、指定した ID の順に駅を返します。`sids` のディープリンクで開いた経路は、この問い合わせで駅を取ります。
一方アプリは、経路検索で並びを逆にしたり途中の駅を間引いたりしてから駅リストに入れます。
そのため、`gqlRequest` が応答を受け取った時点で駅の組ごとの表に直して覚え（`src/lib/trackDistances.ts`）、距離を求めるときは組で引きます。
線路の長さが無い区間は、駅どうしの直線距離で代えます。

`ride_stops.distanceSource` は距離の求め方です。

| 値 | 意味 |
| --- | --- |
| `track` | すべての区間を線路の長さで求めた |
| `haversine` | すべての区間を直線距離で求めた（線路の長さを使う前に記録した行を含む） |
| `mixed` | 線路の長さが無い区間だけ直線距離で代えた |

線路の長さを使うようになる前に記録した乗車は、直線距離のまま残します。計算し直すには当時の駅リストが要りますが、記録には残していないためです。

## 駅の座標と経路

`ride_stops.latitude` / `ride_stops.longitude` は、その駅の座標です。
`ride_stops.pathFromPrevious` は、直前に記録した駅からその駅までのあいだに通った駅の座標です。両端の駅は含みません。
距離と同じく乗車中の駅リストをたどって求めるので、GPS が途切れて検出できなかった駅も入ります。
環状線は、距離を測ったのと同じ回り方の駅を入れます（`measureRideSegment`、`src/utils/rideDistance.ts`）。
値は `[緯度, 経度]` の配列の JSON です。

この3列は、移動経路の地図を足したときに追加しました。
それより前に作った DB には、初期化のときに `ALTER TABLE` で列を足します。
足す前に記録した行は `null` のままです。当時の駅リストが残っておらず、埋められないためです。

## 駅の都道府県

`ride_stops.prefectureId` は、その駅の都道府県です。
StationAPI の `Station.prefectureId`（1〜47）をそのまま入れます。
名前は `src/constants/province.ts` の `PREFECTURES_JA` / `PREFECTURES_ROMAN` を
`prefectureId - 1` で引きます。
1〜47 の外の値は名前を引けないので、`null` にします。

この列は、都道府県ごとの集計を足したときに追加しました。
座標の列と同じく、それより前に作った DB には初期化のときに `ALTER TABLE` で列を足します。
足す前に記録した行は `null` のままです。

## 集計

集計は `src/utils/rideStats.ts` の純関数で行い、
フッターの振り返りタブ（`src/screens/RideReview.tsx`）に表示します。
振り返りを有効にしたユーザーには、ホームにも今月の距離と時間のカード
（`src/components/RideMonthCard.tsx`）を出します。読み出しは `getRideSessionsStartedBetween`（`src/lib/rideLog.ts`）です。

- 期間は今週・今月・今年の3つです。週は月曜日から日曜日までの7日間で、月や年をまたぐ週も7日のまま数えます。
- 日付は端末のタイムゾーンで区切ります。乗車は、乗りはじめた時刻（`startedAt`）が入る期間と日（年は月）に数えます。
- 1回の乗車の距離は、出発駅から最後に到着を検出した駅までの `distanceFromPrevious` の合計です。最後の到着より後に通過だけを検出した駅は数えません。
- 1回の乗車の時間は、`startedAt` から最後に到着を検出した時刻までです。
  ETA 上の所要時間（`etaMinutesFromPrevious` の合計）の方が長ければ、そちらを使います。
  遅れたときは検出した時間の方が長くなるので、そのまま使います。
  最後の駅で ETA を引けていない乗車は、検出した時間だけを使います。
- 接続駅を続けて記録した2つ目の駅（同じ駅グループで、あいだに駅を挟まないもの）は、乗った駅間として数えません。
  最後の到着にも、路線ごとの集計にも入れません。
  このような駅しか到着が無い乗車は、乗車回数にも数えません。
- 駅を検出する間隔が 90 分（`MAX_STOP_GAP_MS`）を超えたら、その手前の駅で乗車が終わったとみなします。アプリを開いたまま放置した乗車で時間が膨らまないようにするためです。
- 路線ごとの距離は、駅と駅のあいだを到着した側の駅の路線に数えます。直通運転で路線が変わる乗車も、区間ごとに分けて数えます。

## 移動経路の地図

振り返りタブの「移動経路」カードに、選んでいる期間の乗車を地図の上に路線色の線で描きます。
カードの全画面ボタンで開く画面（`src/screens/RideRouteMap.tsx`）では、地図を動かせます。
線は `src/utils/rideRoutes.ts` の `buildRideRoutes` で組み立てます。

- 集計と同じ乗車・同じ駅の範囲を描きます。`measureRide` が集計に使った駅だけをたどります。
- 検出した駅どうしのあいだは、`pathFromPrevious` の駅でつなぎます。
- 駅と駅のあいだは、到着した側の駅の路線色で描きます。路線ごとの距離と同じ数え方です。
- 同じ区間を通った乗車が多いほど、線を太くします。期間でいちばん多い回数に対する割合で、3段階に分けます。
- 駅の座標が無い乗車は描きません。その回数をカードに添えます。期間の乗車がすべてそうなら、地図の代わりに理由を出します。

地図の表示には `react-native-maps` を使います。地図の地は、Android では Google マップ、iOS では Apple マップです。
Android の Google マップのキーは、ビルド時の環境変数 `GOOGLE_MAPS_API_KEY` から
`AndroidManifest.xml` に入れます（`android/app/build.gradle` の `manifestPlaceholders`）。
キーはリポジトリに置きません。手元では `.env.local` に書きます。
`.env.local` の値は、`npm run android` / `npm run android:local`（`expo run:android`）で
ビルドしたときだけ環境変数になり、Gradle に渡ります。
Android Studio や `./gradlew` を直接実行するときは、`GOOGLE_MAPS_API_KEY` を環境変数として設定してください。
設定しないとキーが空のままビルドされ、アプリは落ちませんが地図には何も描かれません。
Canary と本番では別のキーを使います。GitHub Actions では `DEV_GOOGLE_MAPS_API_KEY` と
`PRODUCTION_GOOGLE_MAPS_API_KEY` に登録し、各ワークフローが `GOOGLE_MAPS_API_KEY` として渡します。
EAS では環境（`development` / `production`）ごとに `GOOGLE_MAPS_API_KEY` を登録します。

## 都道府県ごとの集計

振り返りタブの「訪れた都道府県」に、選んでいる期間に訪れた都道府県の数と、都道府県ごとの距離を出します。
集計は `src/utils/ridePrefectures.ts` の `summarizeRidePrefectures` で行います。

- 集計と同じ乗車・同じ駅の範囲を数えます。`measureRide` が集計に使った駅だけをたどります。
- 訪れた都道府県は、到着を検出した駅（出発駅を含む）の都道府県だけです。通過駅は数えません。
- 距離は、駅と駅のあいだを到着した側の駅の都道府県に数えます。路線ごとの距離と同じ数え方です。到着した側が通過駅でも、その駅の都道府県に数えます。
- 通過しただけで、どの駅にも到着していない都道府県は一覧に出しません。その距離も出しません。
- 一覧は距離の長い順です。6都道府県以上あるときは上位5件だけを出し、残りは「すべて表示」で開きます。
- 都道府県の分かる駅が1つも無い乗車は数えず、その回数をカードに添えます。期間の乗車がすべてそうなら、一覧の代わりに理由を出します。
