# 振り返り機能の乗車ログ

振り返り機能 ([#5751](https://github.com/TrainLCD/MobileApp/issues/5751)) が集計に使う乗車ログの記録方法をまとめます。

## 記録するユーザー

記録はオプトインです。
`rideLogEnabledAtom`（MMKV キー `@TrainLCD:rideLogEnabled`）が `true` のときだけ、
Main 画面に記録用の `FxRideRecorder` をマウントします。既定は `false` です。

設定は「設定 > 振り返り」（`src/screens/RideLogSettings.tsx`）で切り替えます。
オフにしても保存済みの記録は消しません。
記録を消すのは、同じ画面の「記録をすべて削除」だけです。
削除は記録の書き込みと同じ列（`enqueueRideLogMutation`）に並べて実行します。
Main 画面を抜けたときの最後の書き込みが終わってから消すので、削除した乗車が作り直されることはありません。

## 保存先

端末内の SQLite (`rides.db`) にだけ保存します。サーバには送りません。利用者の位置の座標は保存せず、検出した駅と時刻だけを持ちます。

| テーブル | 1行の意味 |
| --- | --- |
| `ride_sessions` | 1回の乗車。開始・終了時刻、路線、種別、方面 |
| `ride_stops` | 乗車中に検出した駅。`kind` は `arrived`（到着）か `passed`（通過） |

時刻はエポックミリ秒で持ちます。週・月・年への振り分けは、集計する側が端末のタイムゾーンで行います。路線名・路線色・駅名は記録した時点の値を残します。駅データが後から変わっても、過去の記録を表示できるようにするためです。

## 1回の乗車

- Main 画面を開いてから抜けるまでを1回の乗車として扱います。
- 画面を開いた時点の駅を出発駅とします。
- 出発駅の次の駅への到着を1回検出するまでは、DB に書かずメモリに溜めます。画面を開いただけのセッションや、ホームで待っているだけのセッションを数えないためです。通過駅を検出しただけでは確定しません。
- 確定したら、それまでに検出した駅をまとめて1トランザクションで書きます。書き込みに失敗したら、次に駅を検出したとき・発車したとき・Main 画面を抜けるときに、それまでの駅ごと書き直します。書く内容は書き込みを実行する時点のメモリから決めるので、書き込み待ちのあいだに検出した駅も取りこぼしません。以降は駅を検出するたびに追記するので、アプリが終了されても最後の到着までは残ります。
- オートモードを一度でも有効にしたら、Main 画面を抜けるまで記録しません。オートモードの駅移動は実際の乗車ではないためです。

## 時刻

- `ride_sessions.startedAt` は、出発駅を発車した時刻です。発車を検出できなかった場合は、Main 画面を開いた時刻にします。
- `ride_sessions.endedAt` は、最後に到着を検出した時刻です。通過では更新しません。
- `ride_stops.departedAt` は、駅の到着圏を出た時刻です。出入りを繰り返した場合は、最後に出た時刻で上書きします。

## 距離

`ride_stops.distanceFromPrevious` は、直前に記録した駅からの距離（メートル）です。出発駅は 0 です。

線路長のデータは持たないため、乗車中の駅リスト上で2駅のあいだにある駅をたどり、
隣り合う駅どうしの直線距離を合計します（`src/utils/rideDistance.ts`）。
GPS が途切れて途中の駅を検出できなかった区間も、この方法で埋めます。カーブの多い区間では、実際の線路長より短くなります。環状線は、短い方の回り方をとります。

`ride_stops.distanceSource` は距離の求め方です。今は `haversine`（直線距離の合計）だけです。線路の長さで計算するように変えたとき（[#7103](https://github.com/TrainLCD/MobileApp/issues/7103)）に、記録済みの行と見分けるために持ちます。

## 集計

集計は `src/utils/rideStats.ts` の純関数で行います。読み出しは `getRideSessionsStartedBetween`（`src/lib/rideLog.ts`）です。

- 期間は今週・今月・今年の3つです。週は月曜日から日曜日までの7日間で、月や年をまたぐ週も7日のまま数えます。
- 日付は端末のタイムゾーンで区切ります。乗車は、乗りはじめた時刻（`startedAt`）が入る期間と日（年は月）に数えます。
- 1回の乗車の距離は、出発駅から最後に到着を検出した駅までの `distanceFromPrevious` の合計です。最後の到着より後に通過だけを検出した駅は数えません。
- 1回の乗車の時間は、`startedAt` から最後に到着を検出した時刻までです。
- 駅を検出する間隔が 90 分（`MAX_STOP_GAP_MS`）を超えたら、その手前の駅で乗車が終わったとみなします。アプリを開いたまま放置した乗車で時間が膨らまないようにするためです。
- 路線ごとの距離は、駅と駅のあいだを到着した側の駅の路線に数えます。直通運転で路線が変わる乗車も、区間ごとに分けて数えます。
